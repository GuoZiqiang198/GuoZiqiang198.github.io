Owner's writing desk · LLUVIA

把今天的想法，写进雨里。

这是网站所有者的创作入口。首次使用先通过 GitHub Token 登录；之后点击主按钮，就会直接进入新文章编辑表单。

创建新文章  → 管理已有文章
  1. 01 / LOGIN 验证身份

    使用 GitHub 页面生成的 Token 登录，只在自己的可信浏览器操作。

  2. 02 / WRITE 专注写作

    填写标题、标签和正文，也可以上传文章头图。

  3. 03 / PUBLISH 直接发布

    保存后提交到 main，GitHub Pages 自动更新网站。

安全提示：本页不保存任何密码或 Token。不要在公共电脑登录，也不要把 Token 发到聊天、截图或仓库中。
